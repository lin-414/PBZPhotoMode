# DualSense 无法用 L3+R3 进摄影模式 —— v1.4.0 修复计划

## Context（根因）

玩家日志（2026-10-30）关键证据：
- `加载完成 v1.0.18-cpp ... （XInput 已加载：C:\WINDOWS\SYSTEM32\XInput1_4.dll）` — XInput 本身加载正常
- `手柄扫描正常：暂未发现手柄，持续扫描中`，且全程每秒的 `输入诊断` 行 `手柄槽位=-1`

**根因**：模组手柄支持是 XInput-only（`src/win_input.cpp:375-397` 只轮询 `XInputGetState`）。DualSense 在 Windows 上不是 XInput 设备，而是标准 HID/DirectInput 手柄，`XInputGetState` 四个槽位永远返回未连接 → 模组永远看不到手柄 → L3+R3 无效。游戏本体走自己的输入栈，所以手柄能正常玩游戏。
玩家装的是 v1.0.18 旧包，但当前 1.3.0 同样只有 XInput——升级不解决，必须加后端。

**玩家临时方案**（写进 README + 回复话术）：Steam 库 → PBZ → 属性 → 控制器 → 覆盖「启用 Steam 输入」（或 Steam 设置 → 控制器 → 启用 PlayStation 控制器支持），Steam 会虚拟出 Xbox 手柄供 XInput 识别；副作用是全游戏按键提示变 Xbox 样式。

## 方案：新增 DirectInput8 轮询后端（v1.4.0，已确认选型）

消费端零改动：DInput 快照翻译成 `core/gamepad.h` 的 `PadState`，组合键/死区/`InputLogic` 全部复用。

### 1. `src/core/gamepad.h/.cpp`（进测试构建，纯逻辑）
新增：
- `bool dinput_button_to_pad(int index, PadButton& out)` — DualSense/DS4 标准 Windows 映射（rgbButtons 0 基）：0=□(X) 1=╳(A) 2=○(B) 3=△(Y) 4=L1(LB) 5=R1(RB) 6/7=L2/R2 数字镜像(LT/RT) 8=CREATE(Back) 9=OPTIONS(Start) **10=L3(LS) 11=R3(RS)** 12=PS(Guide) 13=触摸板(忽略)
- `void dinput_pov_to_buttons(DWORD pov, bool out[4])` — POV 0/9000/18000/27000 → 上/右/下/左，居中（低字 0xFFFF）全松
- `double dinput_axis_normalize(...)` — 摇杆轴 0..65535 中心 32767.5 → ±1（Y 取反），扳机 lRx/lRy 0..65535 → 0..1

### 2. `src/win_input.cpp` + `src/win_input.h`（DInput 后端）
- `load_dinput()`：仿 `load_xinput()`（L40-66）——System32 优先动态加载 dinput8.dll（绕开游戏目录代理 DLL），`GetProcAddress("DirectInput8Create")`；在 `install()`（L252-269）里调用，供启动日志报告可用性。`#define DIRECTINPUT_VERSION 0x0800` 后用 `<dinput.h>` 类型（只用类型+函数指针，不链 dinput.lib）；自绘 DIJOYSTATE2 的 `DIDATAFORMAT` 表。
- 设备管理全在 `poll()` 所在引擎 Tick 线程（遵守 win_input.h L87 的无锁约定）：惰性 `CoInitializeEx` → `EnumDevices(DI8DEVCLASS_GAMECTRL)`（多个设备时优先 Sony VID 0x054C）→ `CreateDevice` → `SetDataFormat` → `SetCooperativeLevel(隐藏窗口, DISCL_BACKGROUND|DISCL_NONEXCLUSIVE)` → `SetProperty(DIPROP_RANGE 0..65535)` → `Acquire`。失败限流重试（约 2 秒一次）；读失败连续 3 帧释放重枚举（对齐 XInput 拔出判定 L381-385）。合作级窗口：poll 里惰性自建一个隐藏消息窗口（raw sink 窗口在别的线程，不跨线程用）。
- `poll()` 手柄段（L375-400）改三态：XInput 槽位已锁定 → XInput 快照（不变）；否则 DInput 已获取 → `Poll()+GetDeviceState` 翻译为 PadState；否则空快照。**XInput 优先**防止 Xbox 手柄在两套 API 重复出现。
- 一次性诊断：DInput 首次活动时打一行设备实例名 + VID/PID + 按钮位图 + 轴值（映射与真机有出入时远程排查用）。
- 新接口：`pad_backend()`（返回 "XInput 槽位 N" / "DInput: <名>" / "无"）；`pad_connected()` 改为 XInput 槽位 || DInput 已获取；`pad_api_module()` 语义不变。
