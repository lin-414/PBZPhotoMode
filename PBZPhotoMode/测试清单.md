# 测试清单（PBZ Photo Mode v1.0.4）

> 这份清单是给"第一次在游戏里跑"用的。按顺序走一遍，哪一步和预期不一样就记下来。
> 出问题时最有用的东西是 `游戏目录\ue4ss\UE4SS.log` 里以 `[PBZPhotoMode]` 开头的所有行。

---

## 0. 装之前

- [ ] 游戏根目录（含 `PBZ.exe` 的那层）里有 `dwmapi.dll` 和 `ue4ss\` 文件夹
- [ ] `ue4ss\UE4SS.log` 存在，且里面能看到别的 mod 或 `Starting Lua mod` 字样
      （说明 UE4SS 本身在正常工作；这个包里没控制台窗口是正常的）

## 0.5 上机后先确认这两件事（1.0.2 新加）

- [ ] 按 F2 后日志里有 `视口切换成功：...` 这行（说明相机真的接管了画面）
- [ ] 日志里的输入来源行，`备用(Pawn yaw=... / PC yaw=...)` 至少有一个 `true`（走 raw 时不用管）
- [ ] 日志里有 `已让控制器忽略移动输入`（首选）或 `已冻结角色移动`（兜底）—— 之后按 WASD 人不会走
- [ ] 日志里有 `已隐藏主角模型` —— 画面里看不到角色本体
- [ ] 走备用输入源（`-> 使用 look_deg`）时，进模式后随便动一下鼠标，
      还会多出一行"已屏蔽游戏按键"或"视角输入断了，已还原"，两种都属正常

## 1. 安装

- [ ] 把 `PBZPhotoMode` 整个文件夹放到 `游戏目录\ue4ss\Mods\PBZPhotoMode\`
- [ ] 确认路径是 `...\ue4ss\Mods\PBZPhotoMode\Scripts\main.lua`
      （`Scripts` 首字母大写，`main.lua` 全小写，别多套一层）
- [ ] `...\ue4ss\Mods\PBZPhotoMode\enabled.txt` 存在
- [ ] 启动游戏，看日志里有没有这两行：

```
[PBZPhotoMode] 输入来源: InputKey=? InputAxis=? AddControllerYaw/Pitch=? -> 使用 raw/look_deg/none
[PBZPhotoMode] 就绪：游戏内按 F2 打开摄影模式
```

**`-> 使用` 后面是哪个值，直接决定了后面哪些功能可用，请记下来。**

## 2. 基础开关

- [ ] 进入能自由行动的场景，按 `F2` → 右下角出现菜单，标题是 `PBZ PHOTO MODE v1.0.4`
- [ ] 按 `F2` 再按一次 → 菜单消失，镜头回到角色（角色能正常跑动）
- [ ] 再进出一次，确认反复切换不残留（角色能动、没有卡成静止画面）

## 3. 视角与移动（`-> 使用 raw` 时的预期）

- [ ] 按住 `Alt` 推鼠标 → 镜头转，松开 `Alt` 推鼠标 → 镜头不动
- [ ] `W A S D` 平移，`Shift` 明显更快，`Ctrl` 明显更慢
- [ ] `Q` / `E` 下降 / 上升
- [ ] **按住鼠标左键** → 镜头持续上升；**按住右键** → 持续下降
- [ ] 上下看的角度卡在接近垂直（约 89°）不会翻过去

## 3'. 视角与移动（`-> 使用 look_deg` 时的预期）

- [ ] 按住 `Alt` 推鼠标 → 镜头转（这条必须正常）
- [ ] 单击 `W` → 镜头**前进一小步**（约 120cm），按住不会连续跑
- [ ] 单击左键 → 上升一小步（约 60cm），单击右键 → 下降一小步
- [ ] 小键盘 `+` / `-` → FOV 变大 / 变小

## 4. FOV

- [ ] 滚轮前滚 → 视野变广（数字变大），后滚 → 变窄
- [ ] 一直滚到两端会卡在 15 / 150，不会翻转
- [ ] 菜单里 `WHEEL : FOV xx.x` 的数字跟着变

## 5. 菜单与冻结

- [ ] `T` → 菜单消失；再按 `T` → 回来
- [ ] `F` → 角色定格（走路/攻击/特效/粒子全停），但相机还能自由移动
- [ ] 菜单副标题从 `live` 变成 `FROZEN`
- [ ] 再按 `F` → 一切恢复，包括时间流速正常（不是慢动作）

## 5'. 角色隐藏 / HUD / 快门（1.0.4 新加）

- [ ] 进摄影模式后画面里看不到主角模型（转一圈确认没残影）
- [ ] 按 `F2` 退出后角色重新出现（位置没变）
- [ ] 把 `hide_game_hud` 改成 `true` 重启后：进模式血条/小地图消失，退出恢复
- [ ] 按 `F9` → 菜单闪一下消失、日志出现 `已触发截图`
- [ ] 去 `PBZ/Saved/Screenshots` 确认多了一张图，且图里没有我们的菜单文字

## 6. 健壮性

- [ ] 摄影模式下切换场景 / 读档 → 自动退出摄影模式，不崩、不残留冻结
- [ ] 摄影模式下按 `Esc` 开菜单再回来 → 相机还在（或安全退出）
- [ ] 退出游戏不留异常（重新进游戏再按 `F2` 正常）

## 需要反馈的信息

1. 日志里 `输入来源: ... -> 使用 ___` 那一行的完整内容
2. 出问题的是第几步，现象是什么（截图/录屏最好）
3. `游戏目录\ue4ss\UE4SS.log` 整个文件（或者 `[PBZPhotoMode]` 开头的所有行）
4. 游戏分辨率 + 是否存在 UI 缩放

## 常见现象的快速对策

| 现象 | 先改这个 |
| --- | --- |
| 按 F2 完全没反应 | 检查 `Scripts` 大小写 / `enabled.txt` 位置；日志里搜 `PBZPhotoMode` |
| 视角转不了，日志是 `none` | 把日志发我，需要换 hook 目标 |
| 游戏视角被鼠标带着一起转 | `config.lua` → `block_game_input = "full"`（会连鼠标视角一起停） |
| 退出后角色不能动 | `config.lua` → `block_game_input = false`；仍不行再设 `ignore_move_input = false` |
| 菜单跑出屏幕 / 被裁掉 | `config.lua` → `menu_pad_top` / `menu_pad_left` 填具体数字 |
| 左右上下是反的 | `config.lua` → `invert_y = true` |
| 转视角太快/太慢 | `config.lua` → `look_sensitivity` 调小/调大 |
| 移动太慢/太快 | `config.lua` → `move_speed`、`tap_step` |
| 帧数掉了 | `config.lua` → `loop_interval_ms` 改成 16 |
| 按键没反应 / 想改键 | `config.lua` 顶部三个键位 + 打开 `debug_log_input = true` 看日志里有没有按键事件 |
